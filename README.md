# Number Guessing Game

A simple number guessing game built with JavaScript.

## Features
- Random number generation between 1 and 100
- 10 attempts to guess the correct number
- Input validation
- Hints for higher or lower guesses
- Game over message when attempts run out

## Technologies
- JavaScript

## How to Run
1. Open the project in Visual Studio Code.
2. Open the `index.js` file.
3. Run the game in a browser environment that supports `prompt()` and `console.log()`.
